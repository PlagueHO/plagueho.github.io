The **Foundry Agentic Workshop** takes engineers from L200 to L400 through building hosted and prompt-based agents, multi-agent tools, knowledge retrieval, and agentic applications with Microsoft Foundry.

The workshop supports both individual self-learning and facilitator-led group labs, with end-to-end scripts for provisioning the shared Azure environment.
