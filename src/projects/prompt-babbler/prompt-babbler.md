**Prompt Babbler** captures stream-of-consciousness speech, transcribes it with Azure AI Speech, and generates structured prompts through configurable templates and Microsoft Foundry models.

The application offers prompt history, reusable templates, and an MCP server so compatible AI clients can work with saved voice notes and generated prompts. Its React frontend and .NET backend are orchestrated locally with .NET Aspire and can be deployed to Azure.
