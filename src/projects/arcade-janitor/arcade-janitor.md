**ArcadeJanitor** is a focused command-line application and Model Context Protocol server for cleaning and maintaining MAME ROM collections. It can query, filter, audit, move, and delete ROMs using MAME and category metadata, with local caching for downloaded or generated metadata.

The first release deliberately concentrates on MAME ROM folders and a simple, fast workflow that can be used directly at the command line or through an AI agent.
