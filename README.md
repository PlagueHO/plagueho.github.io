## Dependency maintenance

Dependabot follows `dependabot-monthly-v1`: routine version updates are checked
on the first day of each month at 09:00 `Pacific/Auckland` time, using native
monthly scheduling so daylight saving is handled by the timezone. Minor and
patch updates are grouped per ecosystem and directory as
`github-actions-minor-and-patch`, `devcontainers-minor-and-patch`, or
`npm-minor-and-patch`; major updates remain individual pull requests.

Security updates are grouped separately as `github-actions-security`,
`devcontainers-security`, or `npm-security`. They remain event-driven and are
not delayed by the monthly schedule or release-age cooldown. To check routine
updates outside the normal window, go to **Insights** > **Dependency graph** >
**Dependabot**, then use **Recent update jobs** > **Check for updates** for the
relevant manifest. A manual check can create activity outside the monthly
window.
